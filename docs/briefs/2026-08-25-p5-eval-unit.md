## Vol-normalized twin estimator (closes D-026 estimator)

Causal 24h realized vol on the D-022 index:

```
r_u     = log(P_u / P_{u-1})          # 1-minute
σ_t     = sqrt(sum r_u^2 on (T-1440m, T])
x_t     = κ · σ_t
```

Require ≥ 720 finite returns, else the twin row is missing. Barrier is
frozen at T (not path-updating). Twin labels use the same first-passage
labeller as D-007, replacing the 2% distance with `x_t`, same 1h/4h
horizons, both signs.

κ is locked on **D-023 development only** (2020-01-01 .. 2023-12-31):

```
κ = 0.02 / median(σ_t)
```

over development decision timestamps with defined σ. Six decimals.
Applied unchanged to validation and test. No 2025/2026 look when
locking κ.

Fixed ±2% remains the scaffolding label. Any later PASS headline must
report the twin family alongside (D-026). Construct-only work may still
use fixed ±2% alone.
