# Oracle v0 evidence synthesis

Governance checkpoint, 2026-08-25. This synthesis reconciles only committed
Oracle evidence through EXP-005. It creates no experiment, changes no experiment
verdict, inspects no new effect, and authorizes no feature, source, or science
beat.

## 1. Executive conclusion

Oracle v0 is **operationally closed but scientifically inconclusive**. The lab
has built a defensible label population, chronological evaluation discipline,
provenance controls, and a reusable price-only comparator. It has also learned
that the first two fuel implementations are not usable: fills plus asset
contexts cannot reconstruct a sufficiently complete Hyperliquid pre-state
topology, and `cex_oi_cohort_v0` did not clear its frozen construct gate. Those
are measurement-path findings, not proof that directional forced inventory is
irrelevant.

The valid M0 run found positive out-of-sample probability skill but failed the
frozen selectivity and actionability requirements, so M0 is a broad risk-state
or risk-thermostat result and is formally `NULL` for selective warning. The
quoted-impact question was never scored: EXP-003 stopped at `BLOCKED_SOURCE`
because historical impact-notional semantics and quote-at-`T` availability
could not be proven. Complete M1 likewise remains `BLOCKED_ASOF`, not `FAIL` or
`NULL`, because OI and funding archives lack historical publication/receive
evidence.

EXP-005 is formally `BLOCKED_RUN_INTEGRITY`. Its immutable one-shot computation
emitted conditional `NULL` and is directionally immaterial for prioritization,
but the pre-seal validation-outcome inspection prevents that computation from
becoming a predictive verdict. The interaction ladder M2-M5, armed-quadrant
occupancy, ignition, and an exogenous-spark comparison were never reached.
Nothing in the banked record therefore falsifies the underlying interaction
mechanism; equally, nothing supports it predictively.

## 4. Durable deductions

### Findings worth carrying into any Oracle v1

- M0 can grade broad first-passage probability better than climatology while
  still failing as a selective warning system. Probability skill and alert
  utility are separate claims.
- The first CEX directional-fuel proxy is not worth another cosmetic retry.
  A new fuel attempt must be a materially different measurement construct.
- Fill tape is strong propagation and realized-mass evidence but insufficient
  for causal cross-margin pre-state topology without wallet/account state.
- Point-in-time availability is part of construct validity. Economic event
  timestamps and later bulk retrieval cannot substitute for publication or
  receive time.
- Propagation signatures—liquidations, OI clearing, impact expansion—must not
  be promoted into precursors without strict pre-onset timing proof.
- EXP-005's immutable output is useful only for prioritization. Its formal block
  must travel with every mention of the conditional computation.

### Infrastructure and evaluation assets worth retaining

- D-022 consolidated labels, D-014 clusters, D-023 purged chronological splits,
  the fixed/twin first-cause outcome, and the causal hourly risk-set contract.
- Equal-weight probability rows, alert episodes, direction x horizon clusters,
  family-wide UTC-week dependence handling, and explicit common-support rules.
- D-019 provenance sidecars, immutable pre-OOS seals, development firewalls,
  consumed one-shot receipts, and explicit correction records.
- The external immutable raw-data topology, deterministic builders, and the
  Hyperliquid fills Parquet/DuckDB analytical store. Retention is not a license
  to run a new science beat.
- Frozen M0 as a comparator and risk-thermostat reference, not as an entry
  signal or a substitute for complete M1.

### Assumptions not worth carrying forward

- That fills plus `asset_ctxs` can reconstruct cross-margin liquidation
  thresholds without account state.
- That top-trader LSR reweighting of aggregate OI is an observed directional
  liquidation topology, or that relaxing its floor will repair the construct.
- That positive event clusters can define a prospective sampling frame.
- That source coverage proves historical knowability, or that an invented lag
  cures missing publication provenance.
- That positive Brier skill alone implies useful warning selectivity.
- That one exact flow-compression window deserves another OOS look after the
  consumed EXP-005 authorization.

### Measurement debts another statistical model cannot solve

- Historical publication/receive semantics for Binance OI and funding.
- Authoritative versioned impact-notional history and row-level quote-as-of
  semantics for the EXP-003 path.
- Point-in-time wallet/account state for honest cross-margin HL topology.
- A frozen point-in-time external-event/news corpus for H5 and any M2+ slice.

Model complexity cannot manufacture any of those facts. The cost of inspected
OOS periods must also be carried forward: 2025 was spent for the D-029 construct
programme, M0's named validation/test periods have been scored, and EXP-005's
one-shot receipt and conditional OOS computation are consumed. Banked periods
remain valid context and frozen comparators; they cannot be silently retuned,
relabelled as fresh confirmation, or used to repair EXP-005. A later claim needs
an explicitly frozen design and genuinely untouched OOS evidence.

## 6. Recommendation

**Recommend exactly one next bounded design beat: authorize a governance-only
formulation of one narrower Oracle v1 research question. No science beat yet.**

This dominates immediate prospective capture because the missing timestamps
would repair only selected measurement paths while Oracle still has no surviving
fuel construct. It dominates immediate trailing-impact work because choosing a
feature before choosing the narrower question risks repeating measurement-led
drift. The design beat would use only this banked synthesis and existing
contracts to select one causal object and state what evidence would change the
owner's belief.

Authorization would permit one Chair-ready v1 design memo containing exactly
one scientific question, one preceding comparator (normally frozen M0), belief
change, materiality, source/as-of requirements, split/OOS requirements, and a
hard stop. It would **not** authorize data capture, a source hunt, a feature,
implementation, raw-data inspection, model fitting, EXP-006, or any other EXP.

Completion is verifiable when that single memo is banked and this checklist is
either complete or the beat records that no responsible question can yet be
specified. The next Chair/CEO decision point is then to authorize, reject, or
park the one proposed v1 question. Until that decision, Oracle remains stopped
with no active science beat.
